🎬 Movie Guide App — Web Application

A browser-based movie search tool that fetches detailed movie information including poster, rating, plot, cast, and genres using the OMDb API.
----------------------------------------------------------------------------------------------------------------------------------------------------------

🧠 What This Project Demonstrates
Frontend web development
API integration
Asynchronous JavaScript (async/await)
Dynamic UI rendering
Responsive web design
User experience optimization
Handling API errors gracefully
---------------------------------------------------------------------------------
✨ Features
Search movies by name
Display movie poster, title, IMDb rating, and basic info (Rated, Year, Runtime)
Show movie genres dynamically
Display plot and cast
Responsive and mobile-friendly design
User-friendly error messages for invalid or empty input
------------------------------------------------------------------------------------

🛠 Tech Stack
HTML5
CSS3 (Flexbox layout, responsive styling)
JavaScript (ES6+)
Fetch API (for API calls)
OMDb API
--------------------------------------------------------------------------------------

📂 Project Structure
index.html      — Main application interface
style.css       — UI styling, layout, and responsiveness
index.js        — JavaScript: fetch movie data and render results
key.js          — OMDb API key
star-icon.svg   — Star icon for rating display
demo.gif        — Optional demo recording
README.md       — Project documentation
--------------------------------------------------------------------------------------

🚀 How It Works
User enters a movie name in the search bar
JavaScript fetches movie data from the OMDb API
The app dynamically renders:
Poster
Title
Rating
Genres
Plot and cast
Error messages are shown for empty input or movies not found
-----------------------------------------------------------------------------------------

🔐 Security Note
The API key is currently client-side for demonstration purposes.
For production, consider using a backend proxy to protect the API key.
